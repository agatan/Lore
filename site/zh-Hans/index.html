为 Mac 打造的生活日志与语音输入

说过的话，
随时可查。

Lore 把会议和工作中说过的话转写成文字，和日历日程排在同一条时间线上；按下热键说话，就能把整理好的文字输入任何 App。语音识别在 Mac 上完成，录音从不离开你的 Mac。

即将推出 了解功能

macOS 26 或更高版本 · Apple Silicon

生活日志

说过的话，
和日程排在一起。

会议发言、电话、工作时的自言自语，都会保存为带时间的文字，和日历日程排在同一条时间线上。什么时候说了什么，一看便知。

  • 手动开始，或按计划自动记录设定星期和时段（如工作日 9:00–18:00），Lore 只在这段时间内自动记录。
  • 只转写说话的部分静音和环境声不会被转写，只有真正的语音会在 Mac 上识别。
  • 一天的记录，一目了然说话时长、记录数量和日程排在同一条时间轴上，点击任意位置即可跳转到那个时间。

迷你窗口

始终显示在最前面的小时间线，即使在全屏 App 上方也不会消失，还能随手添加备忘。

搜索

用 ⌘F 同时搜索语音、备忘和语音输入。用方向键选择结果，直接跳到当时的位置。

语音备忘录

按下快捷键说话，内容就会作为备忘添加到今天的时间线，原话保留。

语音输入

开口说，
文字就到位。

按下热键说话，Lore 会把整理好的文字直接输入到你正在使用的 App 的光标处。

  • 轻按切换，按住说话默认使用右 Option 键，在任何 App 中都能用，按 Esc 取消。
  • 每个 App 有自己的模式Lore 根据当前 App 自动选择模式，聊天和邮件可以使用不同的整理指令。你添加的词汇适用于所有模式。
  • 整理也在 Mac 上完成默认使用 Apple Foundation Models，也支持本地运行的 Ollama 和 LM Studio。只有你主动选择时才会使用云端 AI。
  • 文字不会丢失整理失败时会输入原始转写；无法输入时，文字会留在剪贴板中。

交给 AI

总结和整理，
交给你的 AI。

Lore 只负责记录，不会生成摘要或待办事项。需要回顾或整理时，把生活日志交给你常用的 AI。

  • CLI用 lore 把一天的记录导出为 Markdown、搜索全部内容，或按日期范围获取 JSON，方便写脚本。
  • MCP在 AI 客户端中添加 lore-mcp，即可按日期或日期范围读取记录。
  • 只读，本地运行两者都在 Mac 上通过 stdio 运行，不会修改你的数据，Lore 也不会为此发起任何网络连接。
# 将今天的记录复制为 Markdown
$ lore export day --clipboard

# 搜索过去的对话
$ lore search "发布计划" --limit 20

# 一周的语音和备忘，输出为 JSON
$ lore range --from 2026-11-09 --to 2026-11-13 --include speech,memos

# 添加到 MCP 客户端
$ claude mcp add lore -- /Applications/Lore.app/Contents/Helpers/lore-mcp

#   life_log_days    life_log_range
#   life_log_export  life_log_search

隐私

你的声音，留在你的 Mac 上。

一款整天开着麦克风的 App，应该先讲清楚数据会去哪里。以下就是全部。

语音识别在 Mac 上完成

使用 Apple SpeechAnalyzer 或你下载的 whisper.cpp 模型转写，不使用云端语音识别。

录音从不外传

语音输入的音频不会保存。生活日志的音频只保存在本机，默认在转写后删除，也可以保留 7 天或 30 天，且从不发送到外部。

云端 AI 只在你选择时使用

只有在设置中选择 OpenAI、Claude、Gemini 或 Groq 时才会用它们整理文字，并且只发送本次转写、通用规则、模式指令和词汇，从不发送音频或生活日志。

同步可选，全程加密

同步会把经过 AES-GCM 加密的文字写入你选择的文件夹，例如 iCloud Drive、Dropbox 或 Syncthing。Lore 不会为同步发起网络连接，音频也不会同步。
