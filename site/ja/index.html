Macのためのライフログと音声入力

言ったことを、
もう忘れない。

会議で引き受けたこと。ひとりごとで思いついたこと。そう決めた理由。Loreはあなたの言葉を予定の隣に残すので、「あのとき何て言ったっけ」と悩まずに済みます。キーを押して話せば、どのアプリにも文章を入力できます。音声認識はMac上で動作し、録音データを外部に送信しません。

GitHubで見る 機能を見る

MITライセンスのオープンソース・macOS 26以降・Apple Silicon

使う場面

記録が役に立つとき。

Loreは作業の邪魔をせずに記録を続けます。その記録が効いてくるのは、1日のうちのこんな場面です。

会議のあとに

ライフログAIをオンにしておけば、予定が終わったときにはもうノートができています。決定事項、やること、未解決の問いを、元の発言につないで残します。

1日の終わりに

発言、メモ、音声入力が予定と同じタイムラインに並ぶので、1日をそのまま振り返れます。ワンクリックでMarkdownに書き出せます。

「あれ、何て言ったっけ」

⌘Fで全期間をまとめて検索。結果を選ぶと、タイムラインのその時刻に移動します。

ライフログ

話した内容を、
予定と一緒に記録。

会議での発言も、作業中のひとりごとも、時刻付きのテキストとして残ります。カレンダーの予定と同じタイムラインに並ぶので、いつ何を話したかがすぐにわかります。

  • 手動でも、スケジュールでも曜日と時間帯（例: 平日9:00〜18:00）を設定すると、その間だけ自動で記録します。
  • 発話だけを文字起こし無音や生活音は文字起こしせず、話している区間だけをMac上で認識します。
  • 記録するのは自分の声ライフログはMacのマイクで聞き取り、通話の音声は取り込みません。オンライン会議では自分の発言が残り、ヘッドホンを使っていれば相手の声は記録されません。
  • 1日の記録をひと目で話した時間、記録の件数、予定を時刻の軸にまとめて表示。クリックするとその時刻に移動します。

ミニウィンドウ

常に手前に表示される小さなタイムライン。フルスクリーンのアプリを使っているときも表示され、その場でメモを追加できます。

検索

発話、メモ、音声入力をまとめて検索（⌘F）。矢印キーで結果を選び、その時刻に移動できます。

ボイスメモ

ショートカットを押して話すと、今日のタイムラインにメモとして追加されます。話した内容がそのまま残ります。

音声入力

話すだけで、
文章を入力。

ホットキーを押して話すと、整形した文章を、使用中のアプリのカーソル位置に入力します。

  • 短く押して切り替え、長押しで話す間だけ既定は右Optionキー。どのアプリでも使え、Escで取り消せます。
  • アプリごとのモード使用中のアプリに応じてモードを自動で選択します。チャットとメールで整形の指示を変えられ、登録した語彙はすべてのモードに反映されます。
  • 整形もMac上で既定はApple Foundation Models。ローカルのOllamaやLM Studioも使えます。クラウドのAIは、自分で選んだ場合だけ使用します。
  • 入力内容は失われない整形に失敗したときは文字起こしをそのまま入力し、入力できないときはクリップボードに残します。

AI連携

要約や整理は、
お使いのAIで。

ライフログAIをオンにすると、会議が終わったときにはもうノートができています。決定事項、やること、未解決の問いを、それぞれ元の発言につないで残します。既定ではオフで、Mac上でもクラウドでも、選んだプロバイダで動きます。それ以外の振り返りは、普段使っているAIにライフログを渡せます。

  • CLIloreコマンドで、1日の記録をMarkdownで書き出したり、検索したり、期間を指定してJSONで取得したりできます。
  • MCPAIクライアントにlore-mcpを登録すると、日付や期間を指定して記録を読み込めます。
  • 読み取り専用、Mac上で動作標準入出力でAIクライアントとつながり、データを変更しません。Lore側から外部へ通信することもありません。
# 今日の記録をMarkdownでコピー
$ lore export day --clipboard

# 過去の会話を検索
$ lore search "リリース計画" --limit 20

# 1週間分の発話とメモをJSONで取得
$ lore range --from 2026-11-09 --to 2026-11-13 --include speech,memos

# MCPクライアントに登録
$ claude mcp add lore -- /Applications/Lore.app/Contents/Helpers/lore-mcp

# MCPのツール
#   life_log_days    life_log_range
#   life_log_export  life_log_search

メニューバー

メニューバーから、すぐに。

ライフログの開始と停止、音声入力、モードの切り替え、直前の結果のコピーまで、メニューバーから操作できます。点の色で現在の状態がわかります。

  • 待機中
  • 録音中
  • 処理中
  • 完了
  • 要確認

プライバシー

音声データは、Macの外に出しません。

1日中マイクを使うアプリだからこそ、どのデータがどこに送られるかを明確にしています。

音声認識はMac上で

Apple SpeechAnalyzer、またはダウンロードしたwhisper.cppのモデルで文字起こしします。クラウドの音声認識は使いません。

録音データは送信しない

音声入力の音声は保存しません。ライフログの音声はMac内に保存し、既定では文字起こし後に削除します（7日・30日も選択可）。どちらも外部に送信しません。

クラウドのAIは選んだときだけ

OpenAI、Claude、Gemini、Groqで整形するのは、設定で選んだ場合だけです。送信するのは今回の文字起こし、共通ルール、モードの指示、語彙のみで、音声は送信しません。ライフログの文章がクラウドのモデルに届くのは、ライフログAIでそのモデルを選び、確認したときだけです。

同期は任意、暗号化して

iCloud Drive、Dropbox、Syncthingなど自分で選んだフォルダに、AES-GCMで暗号化したテキストだけを書き込みます。同期のためにLoreが通信することはなく、音声は同期しません。

話したことを、記録に残す。

LoreはMITライセンスのオープンソースです。署名済みのダウンロード版はまだありません。今すぐソースからビルドするか、GitHubでリリースをフォローして最初の版を受け取ってください。
