主要機能

アプリ別モード

録音開始時の前面アプリからモードを選び、用途に合う指示で文章を整えます。

共通ルールと語彙

全モードに共通する方針と固有名詞を分けて管理し、変更箇所を明確にします。

追跡可能な履歴

生テキスト、結果、モード、指示、エンジン、モデル、処理時間を保存します。

語彙候補

履歴をオンデバイスで分析し、根拠付き候補を提示します。登録には利用者の承認が必要です。

プライバシー境界

録音音声

処理中のメモリだけで扱い、保存も外部送信もしません。

オンデバイス整形

既定値です。文字起こしと指示文は Mac の外へ出ません。

クラウド整形

明示的に選んだ場合だけ、今回の文字起こし、共通ルール、モード指示、語彙を選択先へ送信します。

履歴分析

クラウドの選択にかかわらず、過去履歴の分析は常にオンデバイスで行います。
